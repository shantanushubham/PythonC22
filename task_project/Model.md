# Model

It is a standarised template or format of an important peice of the data
that the backend will accept/deal with for processing.

It may or may not be connected to the Database.

# Entity

It is a template that usually decides the database schema in a backend application, for a given type of data.

<hr>

In case of Django, a model is usually also an entity.
So we can say, Django models are connected to the Database.
